# Governance

Sergio Gallegos is the initial maintainer and owner of architecture acceptance and public releases. Contributors propose focused changes through GitHub Issues and pull requests; the maintainer resolves scope and design disagreements with documented reasons.

ADRs record accepted, proposed and superseded decisions. Research records preserve evidence and uncertainty. Issues own actionable task status; plans hold execution context. No committee, foundation or separate agent governance system is established.

Architecture approval does not authorize publishing releases, using signing credentials, purchasing domains or replacing global developer tools. Maintainer decisions may change scope through explicit updates to ADRs and the current plan.
