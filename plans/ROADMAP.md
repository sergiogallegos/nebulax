# Roadmap

| Stage | Outcome | Status |
|---|---|---|
| A/B/C | Research, proposal and explicit owner decision | Completed; accepted direction in ADR 0001 |
| D | Small reproducible research workspace, docs and verification | Implemented; local validation recorded in handoff |
| 0A | Engine viability, initial baselines and resource observations | Owned graphemes/history/alternate/reflow implemented; foundations and early integration next (see NOW) |
| 0B–0D | PTY/native text/FFI; renderer/storage/scheduling; config proof | Planned in the historical Phase 0 plan |
| 1 | Native macOS engineering MVP with IME/accessibility and required protocols | Not started |
| 2 | Scoped CLI/MCP, typed config transactions, layouts and metadata sessions | Not started; before public release |
| 3 | Public macOS release, signing/notarization, docs/site and measured claims | Not started |
| 4/5 | Linux, then Windows | Deferred |
| 6+ | Splits, graphics and optional process-preserving daemon | Separate future scope |

See [NOW](NOW.md) for the active slice and [Phase 0 methodology](../review/PHASE_0_PLAN.md) for experiment controls. No calendar estimate is justified by the current evidence.
