# Current work

Architecture and Phase D/0 are approved. We are in Phase 0A engine viability. The owned Rust engine has zero dependencies; all 19 existing fixtures pass through 244 replays. `scripts/verify` passes 160 Rust tests plus Unicode and reference-adapter checks. See [latest policy and evidence](../docs/adr/0004-cursor-anchored-resize.md), [architecture status](../docs/architecture/STATUS.md) and [handoff](../HANDOFF.md) for completed work and owner decisions.

The owner-provided Opus feedback set the sequence to **engine foundations before integration**, followed by broader protocol coverage. See the [assessment and sequence](../docs/architecture/FOUNDATION_REVIEW.md).

Resize rejection is resolved: every supported geometry succeeds with cursor-anchored retention and explicit crop/eviction counters, including inactive primary state. See [ADR 0004](../docs/adr/0004-cursor-anchored-resize.md).

The [storage/snapshot experiment](../research/2026-09-26-storage-snapshot-spike.md) is complete: 450 measured samples plus 45 warmups. [ADR 0005](../docs/adr/0005-storage-and-snapshot-direction.md) favors reusable row chunks, owned snapshots and a 16-byte integration candidate, while retaining 8-byte cells as an alternative. Its global-arena retention warning guided the later directly owned integration below. The historical experiment remains a separate reference.

The generic bounded parser and separate semantics are implemented, with ordered typed replies/effects and exact input resumption under output pressure. Twelve new tests cover syntax, cancellation, malformed input, queue limits and delivery order. [ADR 0006](../docs/adr/0006-bounded-parser-and-output.md) defines the contract and intentionally small supported protocol set.

The [single-PTY experiment](../research/2026-09-26-pty-session.md) is implemented: real child replies, controlling terminal, SIGWINCH/geometry, EOF/exit and cleanup, plus deterministic short-write/pressure tests. [ADR 0007](../docs/adr/0007-pty-lifecycle-experiment.md) defines ownership and the narrow unsafe OS-binding exception. It is not an interactive shell/runtime; direct-child reaping can block and job-tree supervision remains open.

The [snapshot/worker/private C boundary](../research/2026-09-26-native-boundary.md) is implemented and tested from C and Swift 6. Snapshots own bounded text, the mailbox retains only its latest frame, checked handles cap in-flight frames, and the worker owns child reaping. [ADR 0008](../docs/adr/0008-snapshot-worker-and-private-ffi.md) records that stage’s limits: full visible copies/row comparison and a prototype idle cadence; the native window followed below.

The [AppKit window/basic-input preview](../research/2026-09-26-native-window.md) now completes the first integrated path. Native-event typing, resizing, Core Text drawing and close after worker cleanup pass. The input mailbox is bounded, partial writes cannot interleave, and duplex echo is drained. One clean Bash prompt/command/exit passes with `TERM=dumb`; this is not broad shell/TUI compatibility. [ADR 0009](../docs/adr/0009-native-window-and-basic-input.md) records scope.

The [cursor/region/application-key slice](../research/2026-09-26-cursor-regions.md) is now implemented. Screen-owned movement, margins, origin, save/restore and region scrolling are tested alongside engine-owned normal/application cursor keys, resize, live PTY replies and the native window. [ADR 0010](../docs/adr/0010-cursor-regions-and-input-modes.md) records the per-buffer and terminal-wide state boundaries.

The [compact core integration](../research/2026-09-26-compact-storage.md) now uses 16-byte cells with a style ID, inline scalars and directly owned cluster tails. Row buffers are reused on steady scrolling; snapshots keep independent exactly sized payloads. Seven added tests and a serial 100-sample comparison validate reclamation and quantify memory gains. Dense/long-cluster resize was slower and remains a measured follow-up. [ADR 0011](../docs/adr/0011-compact-owned-cell-storage.md) records the tradeoff; chunked rows/shared snapshots remain optimizations rather than completed work.

The [bounded style/native slice](../research/2026-09-27-bounded-styles.md) is implemented. Default/indexed/RGB colors and basic attributes use a capped reclaimable table; immutable frames copy their palettes. Twelve new tests plus C/Swift and AppKit evidence cover overflow atomicity, wide-cell erasure, hidden/history/saved state, reflow, ID reuse and native rendering. [ADR 0012](../docs/adr/0012-bounded-styles-and-native-rendition.md) defines exact supported syntax and private ABI v2. No dependency was added.

The [tab/erase slice](../research/2026-09-27-tabs-and-erasure.md) is implemented: shared bounded stops, HT/CHT/CBT/HTS/TBC and standard EL/ED variants with current-background erasure and explicit history/wrap policies. Twelve new core tests plus a clean-shell PTY interaction and native probe cover the behavior; ABI v2 and dependency pins remain unchanged.

The [insertion/deletion slice](../research/2026-09-27-insertion-deletion.md) now implements ICH/DCH/IL/DL using existing cell/row buffers. Ten core tests include an independent wide-owner mapping oracle, streaming partitions, style/lifetime checks, margins and wrap boundaries. A clean Bash interaction and the native probe verify the integrated behavior.

The [autowrap/visibility slice](../research/2026-09-27-autowrap-visibility.md) is implemented: saved screen-owned autowrap, explicit no-wrap wide-owner policy, global cursor visibility and private ABI v3 frame metadata. Ten core tests plus a visibility-only PTY handshake and hidden/visible GUI pixel comparison cover behavior and delivery.

Next bounded task: define truthful device-attribute/status replies and exercise a controlled application-startup probe, keeping advertised capabilities limited to supported behavior. Broader keyboard modes, terminal reset and insert mode remain protocol work. Native marked-text/IME and accessibility remain separate acceptance gates.

The first integration gate—one PTY, engine, bounded snapshot, minimal window and basic input—is implemented as a research preview. Broader protocol/native acceptance remains open. Xcode 27.0/Swift 6.4 are verified, and one headless PTY experiment is verified; a private C/Swift lifetime experiment is also verified. Production lifecycle, native rendering, IME and accessibility remain open.
