# Code of conduct

Treat contributors respectfully. Discuss evidence and code without personal attacks. Harassment, discrimination, threats, disclosure of private information and repeated disruptive behavior are unacceptable.

The maintainer may edit or remove abusive content and restrict participation, explaining decisions when doing so does not expose private information. Good-faith disagreements and corrections are welcome.

Report concerns to the maintainer through an available private contact channel. If no private channel is available, request one without posting sensitive details. No dedicated confidential reporting address is configured yet.
